# Aegis v3.0 客户端交付说明（APP + WebUI）

- 版本：v3.0（versionCode 13）
- 日期：2026-11-09
- 范围：仅 `webui/`、`app/` 与本文件；未改动 `crates/`、`packaging/`、模块脚本或其他模块。

## 1. 本次变更

### 1.1 簇数量通配

- 总览不再假设三簇，卡片数量、顺序与 CPU 区间全部来自 `status.clusters`。
- 支持 2 / 3 / 4 簇以及不连续 CPU 集合；CPU 编号按连续区间显示（如 `CPU 0–2`、`CPU 0–1, 4–5`）。
- `status.clusters` 缺失或为空时显示空态“暂无簇信息”，并提供“重新读取”按钮，不伪造任何簇或频率。
- 实际频率优先取 `status.actual_freq_khz`（与 `clusters` 等长时）；缺失或长度不符才回退 sysfs。

### 1.2 每簇实时占用率（真实采样）

- 进入总览或用户点击刷新时，执行一次固定窗口采样：读取两次 `/proc/stat`，间隔 0.5s。
- 按 `clusters[].cpus` 聚合各 CPU 的 `total` / `idle+iowait` 差值，得到每簇占用率。
- 界面在簇标题处标注“近 0.5s 采样”；采样窗口使用 `/proc/uptime` 实测值，异常时仍以 500ms 窗口计算并显示 `--`。
- 只在刷新时采样一次，没有定时器、没有随机数；真实模式下不会混入任何演示数据。

### 1.3 v3.0 品牌与文案

- `APP_VERSION = 3.0`，顶部版本与页脚统一为 `v3.0`；页脚固定为 `Aegis · v3.0`。
- 总览只展示面向用户的角色、频率、占用与前台信息，不展示内部字段名、文件名、schema 或阶段代号。
- 保留原有深蓝玻璃质感、滑动椭圆托条、可关闭日志抽屉，未推倒重来。

## 4. TOML 配置读写修复（本次重点）

### 4.1 故障定位

- 设备 `tempoctl --config /data/adb/tempo/config.toml config` 的第 82 行为 `reading_packages = [`，
  是跨多行的字符串数组；旧解析器逐行处理，遇到未闭合的 `[` 直接抛错，导致参数页与充电页同时失效。
- 同类结构还包括 `video_packages`、`idx_default_packages` 等，以及 `device.toml` 的 `[[cluster]]`。

### 4.2 解析器重写（`webui/src/toml.js`）

- 支持多行数组、尾随逗号、行内注释、嵌套数组、内联表、点分键。
- 支持数字下划线分隔、十六/八/二进制、`inf`/`nan`。
- 支持基本字符串转义（`\n \t \r \b \f \" \\ \uXXXX \UXXXXXXXX`）与字面量字符串。
- 支持 `[table]` 与 `[[array of tables]]`；`device.toml` 三簇可正确解析为 3 个簇对象。
- 新增 `parseLenient` 容错解析：逐语句跳过坏片段，返回可读部分与错误行号。
- 序列化 `stringify` 保留分组顺序与数组表，输出可被 `tempoctl validate` 接受。

### 4.3 写回不丢配置

- 旧逻辑用内存模型整份重建 TOML，会丢掉界面未暴露的字段（`floor_exit_ratio`、`fg_fast_ms`、
  `tier_table_max`、`startup_guard_ms`、`[scene]` 数组等）。
- 现在以读取到的完整文档为基座，`applyModel` 只覆盖界面暴露的字段；未暴露字段原样保留。

### 4.4 分页降级

- 解析失败时 `loadConfig` 返回 `degraded:true`，参数页与充电页各自用默认值渲染并提示
  “读取失败，已用默认值”，互不拖累；降级状态禁用保存与回滚，避免覆盖设备配置，并提供“重新读取”。
