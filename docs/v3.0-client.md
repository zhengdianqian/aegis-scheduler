# Aegis v3.0 客户端交付说明（APP + WebUI）

- 版本：v3.0（versionCode 13）
- 日期：2026-11-09
- 范围：仅 `webui/`、`app/` 与本文件；未改动 `crates/`、`packaging/`、模块脚本或其他模块。

## 1. 本次变更

### 1.1 簇数量通配

- 总览不再假设三簇，卡片数量、顺序与 CPU 区间全部来自 `status.clusters`。
- 支持 2 / 3 / 4 簇以及不连续 CPU 集合；CPU 编号按连续区间显示（如 `CPU 0–2`、`CPU 0–1, 4–5`）。
- `status.clusters` 缺失或为空时显示空态“暂无簇信息”，并提供“重新读取”按钮，不伪造任何簇或频率。
- 实际频率优先取 `status.actual_freq_khz`（与 `clusters` 等长时）；缺失或长度不符才回退 sysfs。

### 1.2 每簇实时占用率（真实采样）

- 进入总览或用户点击刷新时，执行一次固定窗口采样：读取两次 `/proc/stat`，间隔 0.5s。
- 按 `clusters[].cpus` 聚合各 CPU 的 `total` / `idle+iowait` 差值，得到每簇占用率。
- 界面在簇标题处标注“近 0.5s 采样”；采样窗口使用 `/proc/uptime` 实测值，异常时仍以 500ms 窗口计算并显示 `--`。
- 只在刷新时采样一次，没有定时器、没有随机数；真实模式下不会混入任何演示数据。

### 1.3 v3.0 品牌与文案

- `APP_VERSION = 3.0`，顶部版本与页脚统一为 `v3.0`；页脚固定为 `Aegis · v3.0`。
- 总览只展示面向用户的角色、频率、占用与前台信息，不展示内部字段名、文件名、schema 或阶段代号。
- 保留原有深蓝玻璃质感、滑动椭圆托条、可关闭日志抽屉，未推倒重来。
